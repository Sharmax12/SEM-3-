## Accuracy notes

- The archived NSUT CBCS 2019–20 Biotechnology scheme is used only as a historical topic cross-check.
- Later schedules show NEP-2023 / CBCS course-code pairs. These are search aids, not proof that the 2026 detailed syllabus is unchanged.
- Your current IMS / faculty syllabus, lecture notes and announcements take precedence.
- External university exams are practice material, not NSUT PYQs.
- No complete, publicly searchable NSUT ESE paper set for all five subjects was verified during preparation.

## Materials folder convention

For every subject, store material using this convention:

```text
01_Syllabus/
02_Class_Notes/
03_PYQs/
04_Practice/
05_Error_Log/
```

Only upload files you have permission to share. Do not redistribute restricted library downloads or copyrighted textbook scans.
