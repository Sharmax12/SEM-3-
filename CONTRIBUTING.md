# Adding material to the exam hub

## Folder convention

Use subject folders and keep resource types separate:

```text
subjects/
  <subject>.md
materials/
  <subject>/
    01_Syllabus/
    02_Class_Notes/
    03_PYQs/
    04_Practice/
    05_Error_Log/
```

## Paper naming

Prefer descriptive names such as:

`BTBTC304_Microbiology_MSE_2023-09_NSUT.pdf`

Keep the original filename in the catalogue if renamed. Never infer the year, course code, exam type or university from a filename alone; check the document itself.

## Required metadata

For each paper, add a catalogue row with subject, code, year/session, exam type, original filename, format, text/scan status and evidence for NSUT provenance.

## Copyright and privacy

- Upload only material you have permission to redistribute.
- Do not commit restricted library downloads, paid textbook scans or private student data.
- Redact names, roll numbers, phone numbers and signatures from public copies unless there is a clear right and reason to publish them.
- External university papers must be identified as external practice, never NSUT PYQs.
- Keep the course outline caveat visible: the archived CBCS outline is not proof of the 2026 syllabus.
