# Data Structures & Algorithms (DSA)

**Exam date:** 27 November 2026  
**NEP-2023 code:** BTITC305 · **Archived CBCS code:** BTITC05

> **Syllabus caution:** This topic map comes from the archived NSUT CBCS Biotechnology scheme (2019–20). Confirm the current 2026 IMS/faculty syllabus and the algorithms, language and notation taught in class.

## Topic map

- Arrays, stacks, queues and sparse matrices; time and space complexity.
- Singly, doubly and circular linked lists; stack/queue implementations using linked lists.
- Binary trees, B-trees, N-ary trees and B+ trees; traversals; construction from preorder/inorder; infix-to-postfix conversion.
- Threaded trees, AVL trees, red-black trees, hashing and min/max heaps.
- Graph types, representations, traversals and applications.
- Sequential and binary search, search trees and sorting techniques.

## Daily drill

- [ ] Trace **two problems** by hand. Record every pointer/index change and intermediate structure.
- [ ] Implement or write pseudocode for **one problem**. Include edge cases and clean steps.
- [ ] Answer **three short complexity questions** covering best, average and worst time plus auxiliary space.
- [ ] Spend 10 minutes recreating yesterday's algorithm without looking.
- [ ] Maintain an error log: conceptual error, incorrect trace, implementation bug or complexity mistake.

## Practice prompts

1. Trace insertion and deletion in singly, doubly and circular linked lists.
2. Convert infix expressions to postfix and evaluate the resulting expression.
3. Construct a binary tree from traversal orders and show each traversal.
4. Insert values into an AVL tree and show each rotation.
5. Explain collision handling in hashing and compare the approaches covered in class.
6. Trace BFS and DFS on a graph using both adjacency-list and adjacency-matrix representations.
7. Compare search and sorting algorithms by time complexity and stability where relevant.
